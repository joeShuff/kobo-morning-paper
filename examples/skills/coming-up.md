# Coming Up editorial skill

Use this skill when a source contains future plans, appointments, schedules or dated events.

- Resolve relative dates using the local date supplied in the prompt.
- Prefer explicit calendar dates in the article so the information remains clear when read later.
- Preserve the order of events.
- Do not invent times, venues, attendees, ingredients, prices or other missing details.
- Use a concise newspaper headline and a short standfirst.
- Present a short schedule as a readable list inside one article rather than creating one article per date.
- If a date is ambiguous or the source contradicts itself, state the uncertainty instead of guessing.
